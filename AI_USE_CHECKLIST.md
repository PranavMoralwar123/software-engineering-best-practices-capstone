# Personal AI-Use & Data-Handling Checklist

## 1. AI Tools I Use

| AI Tool | Classification |
|---|---|
| ChatGPT | Consumer / Public |
| Claude | Consumer / Public |
| Gemini | Consumer / Public |

Consumer/public AI tools must not receive sensitive, confidential, proprietary, or personally identifiable information unless the specific tool and data use have been explicitly approved.

## 2. Data I Will Never Paste Into an Unapproved AI Tool

The following categories of information must never be pasted into an unapproved AI tool:

- **Proprietary source code:** Internal repositories, business logic, system architecture, and non-public implementation details.
- **Credentials and secrets:** API keys, passwords, access tokens, private keys, database credentials, and connection strings.
- **Customer and personal data:** Personally identifiable information (PII), user records, financial information, health information, or other sensitive personal data.
- **Confidential business information:** Unreleased plans, contracts, internal documents, business strategies, and other confidential company information.

## 3. AI/Data Policy Review

### Public Policy Reviewed

Policy: OpenAI Privacy Policy  
Source: https://openai.com/policies/privacy-policy/

### Key Takeaway

Before entering information into an AI service, I must understand what information is being submitted, how the service handles that information, and whether I am authorized to share it.

For sensitive, confidential, proprietary, personal, or regulated information, I will use only an AI tool that is explicitly approved for that type of data.

## 4. AI Pre-Flight Check

Before submitting anything to an AI tool, I will check:

- Is the AI tool approved for this type of information?
- Does the prompt contain secrets, credentials, API keys, or tokens?
- Does it contain personal, customer, or sensitive data?
- Does it contain proprietary or confidential information?
- Am I authorized to share the information?
- Can I remove or anonymize sensitive information before submitting it?

**Rule:** If I am unsure whether the information is safe to share, I will not paste it into the AI tool until its use is confirmed as approved.

## 5. Accountability for AI-Generated Code

I am responsible for every line of code I commit, regardless of whether I wrote it myself or an AI assistant generated it.

Before committing AI-generated code, I will:

- Understand what the code does.
- Verify that it is correct and secure.
- Check its dependencies and sources.
- Test the code appropriately.
- Review it for sensitive-data or security issues.
- Be able to explain and defend the code if asked.

**Rule:** AI assistance does not transfer responsibility for the code to the AI tool. I own the final result.
