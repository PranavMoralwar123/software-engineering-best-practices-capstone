# Software Engineering Best Practices

A 6-day capstone focused on professional software engineering practices.

## Topics

- Professional Git workflow
- Secrets management
- Git security and repository hygiene
- Secure coding
- Dependency security
- Testing and code review
- CI/CD
- Production-ready documentation

## Professional Working Rules

- Push work to the remote repository regularly.
- Keep commits small and focused.
- Keep the repository recoverable and up to date.

## Artifact Storage Rule

Code and documentation belong in the approved remote repository, while secrets belong only in environment variables or approved secret managers and are never committed to Git.

## AI Use Rule

Never paste secrets, credentials, customer data, proprietary code, or confidential business information into an unapproved AI tool. Every line of AI-generated code must be reviewed, understood, tested, and owned by the person who commits it.
